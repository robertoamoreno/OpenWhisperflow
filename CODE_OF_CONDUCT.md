# Code of Conduct

OpenWhisperflow aims to be a practical, respectful project for building privacy-conscious desktop voice tools.

Participants are expected to:

- Be respectful and constructive.
- Focus critique on code, behavior, documentation, and design decisions.
- Avoid harassment, personal attacks, and discriminatory language.
- Respect user privacy and never request unnecessary sensitive data in issues or pull requests.

Maintainers may remove comments, close issues, or restrict participation when behavior is disruptive or unsafe for contributors.
